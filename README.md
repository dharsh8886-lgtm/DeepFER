# DeepFER - Facial Emotion Recognition Using Deep Learning

This project uses a CNN model to classify facial emotions into:
- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

Model Accuracy: 55.88%

Files:
- train.py
- app.py
- models/deepfer_model.keras
- models/class_names.txt

Run:
python train.py
python app.py
